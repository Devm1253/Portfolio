## Run Locally

```bash
# Clone the repository
git clone [https://github.com/Devm1253/Devm1253.github.io.git](https://github.com/Devm1253/Devm1253.github.io.git)
cd Devm1253.github.io

# Install dependencies
npm install

# Start local server
npm run dev
